# edu-survey-insight-report

**학술정보교육 설문 정량·정성 통합분석 + 인터랙티브 HTML 보고서 생성 Claude Skill**

대학도서관 학술정보교육의 참여자·설문 데이터를 표준화한 **분석 패키지(ZIP)**를 Claude에 첨부하고, 분석할 교육명과 분석 목적만 알려주면 다음을 수행합니다.

1. 전체 교육과 대상 교육(교육군)의 정량분석 — 공식 집계표와 재계산 결과를 대조해 검증
2. 주관식 원문 전수 재코딩 — 기존 탐색적(PROPOSED) 코딩을 그대로 쓰지 않음
3. 정량·정성 통합 인사이트, 이슈 구조화, 학습자 유형, 공감맵, Pain Point, 문제 재정의, HMW, 차기 교육 개선 권고
4. **독립형 인터랙티브 HTML 보고서** — 필터·비교 차트·응답 분포·상세표·근거(원문·응답ID) 조회, 인쇄용 레이아웃
5. 실제 브라우저(헤드리스 Chromium)로 보고서 동작 자동 검증

> ERICA 학술정보관의 2025~2026 학술정보교육 데이터로 설계·검증했습니다(월간 AI 한입 세션, AI 릴레이 특강, 첫걸음 가이드 분할 영상교육). 같은 형식의 분석 패키지라면 다른 교육군·다른 기관에서도 사용할 수 있습니다.

## 사전조건

### 1. 분석 패키지 ZIP (필수 첨부파일)
이 스킬은 **참여자 및 설문 결과를 표준화·비식별화하여 추출한 분석 패키지**가 있어야 동작합니다. 원본 설문 엑셀이나 구글폼 결과를 그대로 넣으면 동작하지 않습니다.

패키지 버전 `education-analysis-package-v1` 기준 필수 파일:

| 파일 | 내용 |
|---|---|
| `manifest.json` | 패키지·데이터 버전, 실행 ID, 파일별 SHA256, 건수, 검증·개인정보 검사 결과 |
| `educations.csv` | 교육ID·교육명·교육유형·운영방식·교육일·교육대상·신청/참여/응답 수(기준표) |
| `participation.csv` | 참여자 레코드 수, 확인된 이수자 수, 응답률 계산 가능 여부·분모 |
| `survey_responses.csv` | 비식별 응답ID, 교육ID, 응답자 신분 |
| `question_answers.csv` | 문항 응답(원문항, 표준분석항목ID, 수치값, 비교가능성 A~D, 분석포함 Y/N) |
| `qualitative.csv` | 비식별 주관식 원문, 분석 제외 여부(제외 사유) |
| `question_dictionary.csv` | 원본 문항 ↔ 표준 분석 항목 매핑, 응답 척도 |
| `quantitative_summary.csv` | 검증된 공식 집계표(전체교육·교육별 원문항) — 재계산 검증의 기준 |
| (선택) `analysis_rules.md`, `education_groups.csv`, `improvement_history.csv` | 패키지 측 규칙, 승인된 교육군, 개선 이력 |

열 이름·의미는 [`edu-survey-insight-report/references/package_schema.md`](edu-survey-insight-report/references/package_schema.md)에 정리되어 있습니다. 다른 기관에서 쓰려면 이 구조에 맞춰 패키지를 만들어야 합니다(열 이름이 다르면 `scripts/common.py`만 조정).

**개인정보:** 패키지는 비식별 상태여야 합니다(이름·학번·이메일 없음, 익명 응답ID). 스킬은 주관식 원문 속 "OOO박사님/사서님" 형태의 실명을 자동으로 가리지만, 완전한 검사를 대신하지 않습니다.

### 2. Claude 실행 환경
- **Skills를 사용할 수 있고 코드 실행(파일 생성)이 가능한 Claude 환경** — Claude 앱의 코드 실행·파일 생성 기능, 또는 Claude Code
- Python 3.10 이상과 패키지: `pandas`, `numpy` (필수), `scipy` (선택 — 교육 간 차이 검정), `playwright` + Chromium (선택 — 브라우저 자동 검증)
  ```bash
  pip install pandas numpy scipy playwright
  python -m playwright install chromium
  ```
  > 대부분의 Claude 작업 환경에는 이미 설치되어 있어 스킬이 필요할 때만 설치합니다.

### 3. 사용자가 알려줘야 할 것
| 항목 | 예 | 필수 |
|---|---|---|
| 분석할 교육명 / 교육군 / 교육ID | "월간 AI 한입 세션", "릴레이 특강", `2025-릴레이-01~05` | 필수 |
| 분석 목적 | "다음 학기 기획에서 유지·개선할 점 도출" | 필수 |
| 연도 범위 | "2026년만" | 교육군이 여러 해에 걸칠 때 |
| 유사 교육 비교 키워드 | "AI, GPT, 프롬프트" | 권장(없으면 연도별 비교만) |
| 운영상 확인 사항 | "2026년부터 Zoom → 분할 영상교육으로 전환" | 데이터에 없는 맥락이 있을 때 |

## 사용 프롬프트

대화에 **분석 패키지 ZIP을 첨부**한 뒤 아래 문구를 상황에 맞게 바꿔 사용하세요. `[ ]` 부분을 채우면 됩니다.

### 기본
```
첨부한 분석 패키지로 [2026학년도 1학기 월간 AI 한입 세션] 교육을 분석해 줘.
분석 목적은 [다음 학기 세션 기획에서 무엇을 유지하고 무엇을 개선할지 근거를 찾는 것]이야.
전체 교육과 비교하고, 공감맵·HMW·개선 권고가 들어간 인터랙티브 HTML 보고서로 만들어 줘.
```

### 결과를 먼저 채팅으로 검토하고 싶을 때
```
첨부한 분석 패키지로 [AI 릴레이 특강]을 분석해 줘. 목적은 [연구자 대상 AI 특강 개선]이야.
HTML은 아직 만들지 말고, 정량·정성 결과와 인사이트·권고를 먼저 채팅으로 보여줘.
내가 검토하고 수정사항을 주면 그다음에 보고서를 만들어 줘.
```

### 대상 범위를 정확히 지정할 때
```
교육ID [2025-릴레이-01, 2025-릴레이-02, 2025-릴레이-03, 2025-릴레이-04, 2025-릴레이-05]만 대상으로 분석해 줘.
유사 교육 비교는 교육명에 [AI, GPT, 프롬프트, 윤리]가 들어간 교육으로 해 줘.
```

### 데이터에 없는 운영 맥락을 알려줄 때
```
참고로 [2026년부터 기존 Zoom 교육을 분할 영상교육(-1~-4)으로 전환했고,
대부분의 학생이 시리즈 전체를 수강·응답했어]. 이 점을 고려해서 집계해 줘.
```

### 같은 패키지로 다른 교육을 이어서 분석할 때
```
같은 분석 패키지로 이번엔 [학술정보관 첫걸음 가이드 2026]을 분석해 줘.
주관식 코딩은 앞에서 검토한 결과(overrides.json)를 재사용하고, 대상 교육 원문만 다시 확인해 줘.
```

### 보고서 수정 요청
```
보고서에서 [권고 R2는 근거가 약하니 '탐색'으로 내리고], [교수 응답자 관련 인사이트를 추가해] 줘.
수정 후 브라우저 검증을 다시 실행하고 결과를 알려줘.
```

> **팁:** 분석 목적을 구체적으로 쓸수록 핵심 답변과 권고가 그 목적에 맞춰집니다. 예: "점심시간 운영 방식을 바꿀지 판단", "교수 대상 별도 세션이 필요한지 판단".

## 진행 과정과 산출물

| 단계 | 스크립트 | 결과 |
|---|---|---|
| 1. 패키지 점검 | `inspect_package.py` | SHA·필수 파일, 데이터 특성(설문 누락·연도 불일치·응답률 범위·분할 운영 단위 등) |
| 2. 대상 확정 | `find_target.py` | 대상 교육 목록(여러 교육군이 걸리면 사용자에게 확인) |
| 3. 정량분석 | `quant.py` | 공식 집계 재현 검증, 연도·유형·운영방식·신분·비교군, 대상 교육별·문항별, 이상 응답 후보 |
| 4. 정성분석 | `qual_prep.py` → 전수 검토 → `qual_finalize.py` | 주제별 고유 응답자 수·언급 수·관련 교육 수 |
| 5. 해석 작성 | `content_skeleton.py` → 작성 → `validate_content.py` | 인사이트·공감맵·HMW·권고(근거 ID 연결, 인용문 원문 대조) |
| 6. 보고서 생성 | `build_report.py` | 독립형 HTML(약 300KB, 외부 연결 없음) |
| 7. 브라우저 검증 | `verify_report.py` | 필터·차트·드로어·근거 조회·모바일·콘솔 오류·인쇄 PDF 검사 |

**최종 산출물:** HTML 보고서 1개 + 채팅 요약(대상, 데이터 버전, 핵심 답변, 검증 결과, 해석 제한 사항)

### 보고서 구성
0 핵심 답변 · 1 데이터 확인 · 2 전체 교육 탐색(필터 연동) · Q 주관식 주제 탐색 · 3 대상 교육 심층(히트맵·분포·비교군·민감도) · 4 통합 인사이트 · 5 이슈 구조화·학습자 유형·공감맵 · 6 Pain Point·문제 재정의 · 7 HMW · 8 개선 권고 · 9 한계·데이터 버전·수치 검증

## 분석 원칙 요약
자세한 규칙: [`references/analysis_rules.md`](edu-survey-insight-report/references/analysis_rules.md)

- 유효 응답 = 분석포함 Y · 숫자 변환 성공 · 비교가능성 A/B. 공식 집계표와 7개 표준 지표가 일치해야 진행
- 응답자 가중 평균과 교육 동일가중 평균을 구분해 함께 제시
- 한 응답자에게 같은 지표 문항이 여러 개면 통합 평균에서 제외하고 문항별로만 제시
- 전반적 만족도를 다른 지표 평균으로 만들지 않음 · 핵심역량 향상 도움도 ≠ 실제 역량 향상
- 난이도처럼 척도 방향이 검증되지 않은 문항은 분포만 제시
- 분할 영상교육(같은 교육군·같은 날짜·여러 회차)은 동일인 응답을 묶은 **추정 인원** 기준을 함께 제시
- 유의성이 확인되지 않은 차이는 단정하지 않음 · 데이터에 없는 원인·의견은 만들지 않음
- 인용문(“ ”)은 원문 그대로만 사용하고 자동 대조 · 우선순위는 점수 없이 단계(우선 검토/검토/탐색/유지)로만

## 주의사항과 한계
- **분석 패키지가 없으면 사용할 수 없습니다.** 원본 설문 파일을 패키지 구조로 표준화하는 과정은 이 스킬에 포함되어 있지 않습니다.
- 주관식 코딩은 Claude 한 명이 수행하므로 코더 간 신뢰도는 검증되지 않습니다. 중요한 의사결정 전에는 담당자가 `qual_review.md`와 코딩 결과를 함께 검토하세요.
- 분할 영상교육의 "추정 인원"은 응답 특성(신분·소속·인지경로)이 같은 응답을 묶은 추정치입니다.
- 대상 교육의 응답·주관식이 적으면(예: 주관식 10명 미만) 유형·공감맵은 잠정적이거나 생략될 수 있습니다.
- 보고서에는 비식별 주관식 원문이 포함됩니다. 외부에 공유하기 전에 내용을 확인하세요.
- 코드북(`assets/codebook.json`)과 일부 판정 기준은 한국어 대학도서관 교육 설문에 맞춰져 있습니다.
