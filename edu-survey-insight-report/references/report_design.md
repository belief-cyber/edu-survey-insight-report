# 보고서 구조·디자인 규칙 (assets/report_template.html)

독립형 HTML 1개(외부 리소스 없음, 시스템 한글 글꼴). `build_report.py`가 `/*__DATA__*/`(원자료)와 `/*__CONTENT__*/`(해석)를 주입한다.

## 섹션
| # | 섹션 | 성격 |
|---|---|---|
| 0 | 핵심 답변(유지·강화 / 우선 개선 / 검토·탐색) | AI 해석, 범위 고정 |
| 1 | 데이터 확인·분석 범위: KPI, 대상 교육 표(자동), 데이터 특성 카드 | 확인 |
| 2 | 전체 교육 정량 탐색: 필터(연도·유형·운영방식·신분·교육군·지표·비교 축·집계 기준) → KPI, 비교 막대, 100% 응답 분포, 교육별 상세표(정렬·행 클릭 드로어) + 고정 해석 카드 | 필터 연동 |
| Q | 주관식 주제 탐색: 대상/그 외 범위, 연도·신분·검색 → 주제 막대(클릭 → 원문) | 필터 연동 |
| 3 | 대상 교육 심층: 교육×지표 히트맵(셀 클릭 → 응답ID 표 → 응답 상세), 분포, 비교군 차트(추정 인원), 문항별 표, 신분·인지경로, 응답 패턴 이상, 교육별 카드, 민감도 토글 | 필터 연동 + 확인 |

| 5 | 이슈 구조화 · 유형 · 공감맵(Says/Thinks/Does/Feels + Pain/Gain/Needs) | 확인 + AI 해석 |
| 6 | Pain Point(근거 강도 막대) · 관계 · 문제 재정의 | 확인 + AI 해석 |
| 7 | HMW | AI 해석 + 근거 |
| 8 | 개선 권고(접이식, 8개 항목) | AI 해석 + 근거 |
| 9 | 한계 · 데이터 버전 · 공식 집계 재계산 검증표 | 확인 |

## 표시 규칙
- 배지: `확인`(초록) / `AI 해석`(보라) / `필터 연동`(파랑) / `해석 제한`(주황).
- 필터 영역에는 AI 해석을 넣지 않는다. 고정 해석은 "범위 고정: …" 배지와 함께 별도 카드에.
- 근거 버튼(원문·응답·교육·주제) → 오른쪽 드로어. 인쇄 시 드로어·필터 버튼은 숨김.
- 색: 범주형 파랑 #2a78d6 / 주황 #eb6834(대상 강조) / 초록 #1baf7a(긍정) / 보라 #6250d6(수요). 리커트 1~5 = 빨강–연빨강–회색–연파랑–파랑(발산형). 다크 모드 토큰 별도 정의.
- 차트: 가는 막대(14px), 4px 라운드, 막대 사이 간격, hover 툴팁, 범례 상시. 평균 막대 축은 데이터 최소값 근처에서 시작(천장효과 가독성)하되 축 눈금으로 시작점을 보여준다.
- 인쇄(A4): 상단 메뉴의 **PDF 인쇄(A4)** 버튼, 또는 브라우저 인쇄(Ctrl/Cmd+P) 모두 같은 인쇄본을 만든다.
  - 인쇄 직전(`beforeprint`/버튼): 모든 `<details>`(권고 등 접히는 부분)를 펼치고, 라이트 테마로 바꾸고, 드로어를 닫은 뒤 다시 렌더링한다. 인쇄가 끝나면(`afterprint`) 화면 상태(테마·펼침)를 되돌린다.
  - 인쇄본에서 숨김: 필터 줄(`.filters`) 전체, 검색창·선택 상자·버튼(근거 버튼 `.ev`는 라벨로만 남김), 목차·테마·인쇄 버튼, "클릭하면 조회" 같은 조작 안내(`.noprint`).
  - 필터 영역 위에 `.print-note`로 "인쇄 시점의 필터 상태로 계산한 결과"임을 밝히고, 현재 범위 줄은 그대로 인쇄한다.
  - 섹션마다 페이지 나눔, 교육별 표는 작은 글씨로 전부. 주관식 원문 목록은 한 열로 펼쳐 모두 싣되, 선택 범위가 40행을 넘으면 40행까지만 싣고 전체 행 수와 "HTML에서 조회" 안내를 붙인다.
  - 새 접힘 요소를 추가할 때는 `<details>`로 만들어야 인쇄 시 자동으로 펼쳐진다. 새 조작 요소(입력창·버튼·안내 문구)는 `.filters` 안에 두거나 `noprint` 클래스를 붙인다.
- 반응형: 820px 이하 1열, 히트맵은 가로 스크롤.

## 템플릿을 고칠 때
- 통계는 반드시 브라우저에서 `DATA.resp`로 재계산(하드코딩 금지). 새 차트는 `agg()`·`eduEq()`를 재사용.
- 새 고정 텍스트는 CONTENT 키를 추가하고 `content_guide.md`·`validate_content.py`·`content_skeleton.py`를 함께 갱신.
- 수정 후 `verify_report.py`를 다시 실행해 전 항목 PASS를 확인.
